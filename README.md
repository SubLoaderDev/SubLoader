# SubLoader

SubLoader is a free browser extension for loading local subtitles or finding subtitles online on supported video platforms.

It currently supports YouTube, Dailymotion, Prime Video, and Netflix.

SubLoader includes features such as subtitle synchronization, video seek controls, dual subtitle tracks, appearance customization, per-video subtitle memory within the current tab session, and OpenSubtitles integration for online subtitle search and downloads.

Local subtitle files are processed directly in Chrome.
