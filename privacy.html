Privacy Policy

Last updated: September 27, 2026

SubLoader does not collect, transmit, sell, or share personal user data. Subtitle files selected by the user are processed locally in the browser.

Information SubLoader collects

SubLoader does not collect personal information, browsing history, authentication information, financial information, location data, communications, or other user data.

Subtitle files

Subtitle files selected by the user are processed locally within Chrome. SubLoader does not upload subtitle files or their contents to SubLoader or to any external server.

Local storage

SubLoader may store extension settings, subtitle preferences, and per-video subtitle information locally in the browser using Chrome's extension storage. This information remains on the user's device unless the browser itself provides a platform-level synchronization feature.

Website access

SubLoader accesses supported YouTube and Dailymotion pages only as necessary to display, synchronize, and control local subtitles on those pages.

Analytics and advertising

SubLoader does not use analytics services, advertising trackers, behavioral profiling, or remote data collection services.

Data sharing and sale

SubLoader does not sell, rent, or transfer user data to third parties.

Changes to this policy

If SubLoader's data practices change in the future, this Privacy Policy will be updated to reflect those changes before any new data collection practices are introduced.

Contact

For questions about this Privacy Policy or SubLoader, please use the official support or project page associated with the extension.
